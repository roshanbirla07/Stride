Set up iPhone sync ↗

One time on your iPhone: make a Shortcut named Stride Sync. It reads your Health step samples and uploads today's total to your account.

Copy this token now. It is shown only once. Generating another token stops the old Shortcut until you replace its token.

  1. Open Shortcuts → +. Name it Stride Sync.
  2. Add Find Health Samples: Type = Steps, Start Date = Today, sort/filter without a sample limit. Give Health access when prompted.
  3. Add Get Details of Health Samples → Value, then Calculate Statistics → Sum.
  4. Add Get Contents of URL. URL: . Set method POST, header Authorization = Bearer YOUR_TOKEN, and request body JSON with key steps and the Sum result as a number. Replace YOUR_TOKEN with the copied token.
  5. Run the Shortcut once, allow network access, then return here and tap refresh if needed. Compare the step total with Apple Health before using the rankings.
Automatic daily upload

Shortcuts → Automation → + → Time of Day → Daily at 11:45 PM IST → Run Immediately → Run Shortcut → Stride Sync. Keep the iPhone on and connected. iOS controls when the automation runs; check the board after the first night.

If iPhone and Apple Watch both record steps, a raw sample sum can count overlapping samples. Check the first upload against Health; filter to your preferred source if totals differ. Uploaded totals replace earlier uploads for the same day. Days close at midnight IST; yesterday's upload is accepted until 12:30 AM IST only if the Shortcut supplies a day value for yesterday.

Results finalize at 12:30 AM IST. Unverified users do not enter the leaderboard.
